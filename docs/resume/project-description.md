## 项目标题

CrowdLaunch AI｜海外众筹营销 Agent 工作台（个人项目）

## 三条项目经历

- 面向 Kickstarter / Indiegogo 众筹运营场景，独立设计并实现机会研究、Launch 规划、广告诊断与 Backer Voice 三类 Agent 工作流，将竞品证据、回报档位毛利、CPC/CVR/ROAS 与风险提示汇总到统一驾驶舱。
- 使用 React/Vinext、FastAPI、SQLAlchemy 与 SQLite/PostgreSQL 构建前后端；将数值计算与大模型生成分层，支持 OpenAI Responses API 可选增强及无 Key 自动回退，保证关键结论可复核、演示可稳定运行。
- 为预算调整、计划上线和回复发送设计 Human-in-the-loop 审批与审计记录，演示版明确禁止外部写入；编写 API 自动化测试并完成响应式界面和 WebMCP 工具验证。

## 面试时可以量化的工程事实

- 3 类业务 Agent：机会研究、增长诊断、Backer Voice。
- 7 个核心 API 路径，覆盖运行记录和人工审批。
- 6 项自动化 API 测试。
- 3 个 WebMCP 工具：页面导航、运行分析、批准建议。
